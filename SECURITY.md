# Reporting a security problem

Please don't open a public issue for a security problem.

Report it privately instead: on this repository's **Security** tab, click **Report a vulnerability** ([direct link](https://github.com/Accessa-suite/signalbox-app/security/advisories/new)). Only the maintainers can see the report.

Useful to include:

- the Signalbox version (Settings → About) and your OS;
- what an attacker could do, and what they would need first;
- steps to reproduce it.

We'll reply to confirm we've received it, and tell you when a fixed version is out. Signalbox updates itself, so a fix reaches installed copies with the next release.

Signalbox runs only on your machine and has no server of its own. Tracker and code-host tokens are kept in the operating system's keychain.
