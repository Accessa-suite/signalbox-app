# Keyboard shortcuts

> Every keyboard shortcut in Signalbox, for Linux and macOS: new ticket, back to the board, the palette, saving files and closing dialogs.

Section: More · Updated: 2026-11-23

These are all the shortcuts Signalbox adds. App-wide shortcuts use Ctrl+Shift on Linux and ⌘ on Mac, so they don't take keys from the shell or the agent in a terminal.

## App-wide

| Action | Linux | Mac |
|---|---|---|
| Open or close the palette | **Ctrl+K** | **⌘K** |
| Open the palette while a terminal has focus | **Ctrl+Shift+K** | **⌘K** |
| New ticket | **Ctrl+Shift+N** | **⇧⌘N** |
| Back to the **Board** tab | **Ctrl+Shift+B** | **⇧⌘B** |

> **Note:** In a terminal on Linux, plain **Ctrl+K** goes to the shell or the agent (it deletes to the end of the line). That's why the palette uses **Ctrl+Shift+K** there.

## In the palette

| Action | Linux | Mac |
|---|---|---|
| Move down / up | **↓** / **↑**, **Ctrl+N** / **Ctrl+P**, **Tab** / **Shift+Tab** | same |
| Move 8 rows | **Page Down** / **Page Up** | same |
| First / last row | **Ctrl+Home** / **Ctrl+End** | **⌘Home** / **⌘End** |
| Open the selected row | **Enter** | **Enter** |
| Leave **Switch project…** or **New crew…** | **Backspace** in the empty box | same |
| Close | **Esc** | **Esc** |

## Dialogs, the drawer and editors

| Action | Key |
|---|---|
| Close the ticket drawer, **New ticket**, **Add a project**, the crew starter, **Setup & run…**, the Write… editor, the daily log or release notes editor, or **Create PR** | **Esc** (closes the top one only) |
| Save a ticket's title in the drawer | **Enter** |
| Save a draft's text, or a checkout label in Settings | **Enter** |
| Add a draft on the **Drafts** page | **Enter** |
| Add a stage branch in the stages editor | **Enter** |

## Changes and Files

| Action | Linux | Mac |
|---|---|---|
| Save the open file | **Ctrl+S** | **⌘S** |
| Rename the selected file or folder in the tree | **F2** | **F2** |
| Confirm a new name, new file or new folder | **Enter** | **Enter** |
| Cancel a rename or new file, or close the tree's menu | **Esc** | **Esc** |

Files also save on their own a moment after you stop typing. See [Files](files.md).

## Terminals

Terminals pass every other key straight to the shell or the agent, so the agent's own shortcuts work as usual.
